# Upgrade to 5.0.0

## Two-level shuffle

Two-level shuffle is enabled by default for eligible exchanges with a fanout of
at least 128. Upgrade coordinators and workers together because older workers
cannot decode its plan variant.

Set the minimum fanout to 0 on the coordinating session to disable it:

```rust
ctx.set_distributed_two_level_shuffle_min_fanout(0)?;
```

The builder equivalent is
`.with_distributed_two_level_shuffle_min_fanout(0)?`. SQL sessions can use
`SET distributed.two_level_shuffle_min_fanout = 0`.

Exhaustive `DistributedConfig` literals must add
`two_level_shuffle_min_fanout: 128` (or 0 to disable it). Custom `DistributedExt`
implementations must add `set_distributed_two_level_shuffle_min_fanout` and
`with_distributed_two_level_shuffle_min_fanout`.
