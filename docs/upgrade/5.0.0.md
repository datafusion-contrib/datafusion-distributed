# Upgrade to 5.0.0

## Two-level shuffle

Two-level shuffle is disabled by default. Upgrade coordinators and workers
together before enabling it because older workers cannot decode its plan variant.

Set a positive minimum fanout on the coordinating session to enable it:

```rust
ctx.set_distributed_two_level_shuffle_min_fanout(128)?;
```

The builder equivalent is
`.with_distributed_two_level_shuffle_min_fanout(128)?`. SQL sessions can use
`SET distributed.two_level_shuffle_min_fanout = 128`.

Exhaustive `DistributedConfig` literals must add
`two_level_shuffle_min_fanout: 0`. Custom `DistributedExt` implementations must
add `set_distributed_two_level_shuffle_min_fanout` and
`with_distributed_two_level_shuffle_min_fanout`.
