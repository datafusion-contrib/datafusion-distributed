# Upgrading from 4.0.0 to 5.0.0

## Iceberg test harness

`IcebergTestHarness::ctx` is private. Configure sessions before `build()` using
`with_target_partitions`, `with_scan_bytes_per_partition`, and
`with_column_stats_enabled`. Use the harness's `query`, `physical_plan`, `scan`,
`estimate_task_count`, and `roundtrip_plan` methods instead of accessing its context.
