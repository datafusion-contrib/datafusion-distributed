# Upgrading from 5.0.0 to 6.0.0

This guide covers the source and behavioural changes merged after the
`v5.0.0` tag.

## 1. Upgrade DataFusion and Arrow dependencies

DataFusion Distributed now targets DataFusion 56, Arrow 60, and Parquet 60.
Applications that depend on these crates directly must use compatible versions
to avoid duplicate, incompatible Arrow and DataFusion types.

DataFusion 56 also changes `TableProvider::scan` to borrow projections as a
slice. Update custom table providers from `Option<&Vec<usize>>` to
`Option<&[usize]>`. If the projection must be retained, clone it with
`projection.map(<[usize]>::to_vec)`.
